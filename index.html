Передать API-ключ зашифрованным файлом

Ключ шифруется в браузере. Открытое значение не отправляется на сайт и не сохраняется этой страницей. Расшифровка доступна серверу-получателю. Это передача доступа, а не запуск торговли.

  1. Вставь только GMGN API Key — не seed и не приватный ключ кошелька.
  2. Нажми «Зашифровать».
  3. Скачай файл и отправь его в личный чат с Tyler.
